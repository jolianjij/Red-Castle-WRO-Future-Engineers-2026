# Printing — sliced, ready-to-print files

Five pre-sliced **3MF** plates (Bambu Studio), one per subassembly, each
containing every part of that subassembly arranged and sliced for the
**Bambu Lab A1** in **PLA+ Silk Silver**:

| File | Subassembly |
|---|---|
| `chasis-ready-to-print.3mf` | base plate, middle plate, top plate, camera holder |
| `steering-ready-to-print.3mf` | Ackermann steering linkage |
| `rear-drive-ready-to-print.3mf` | differential, gears, N20 motor holder |
| `wheels-ready-to-print.3mf` | wheels + shaft mounts |
| `battery slider-ready-to-print.3mf` | battery tray + slider |

Open a `.3mf` directly in Bambu Studio — it carries the plate layout and print
settings, so it reproduces the exact print used for the competition robot.
Source STLs for each individual part are in [`../3d-parts/`](../3d-parts).
