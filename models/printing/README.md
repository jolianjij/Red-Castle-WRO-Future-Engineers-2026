# Printing

Print-ready files and slicer settings.

- Put final STL/OBJ files ready to print here.
- Include the slicer profile/settings file (e.g. .ini, .cfg, or a notes file) used for each part: layer height, infill, supports, material.
- Suggested naming: `PartName_v1.stl`, `PartName_settings.txt`
